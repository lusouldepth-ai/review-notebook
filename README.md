# 儿童学习复盘

面向小学一至六年级家庭的本地学习复盘工具。家长管理多个孩子档案和教材，孩子把当天所学讲给 AI，AI 依据指定教材评估讲解质量并自动生成学习记录。

已实现：
- 手机号/邮箱本地登录
- 按登录账号隔离的本机 SQLite 数据库，重新登录自动恢复孩子和学习记录
- 孩子档案管理（多孩子）
- 后台公共教材库与家庭补充教材（PDF / TXT / Markdown）
- 费曼讲解：文字或语音输入后，由 DeepSeek 依据教材评分
- 自动标记讲清楚、不清楚和不熟悉的部分，并生成更完整的讲法与追问
- AI 评估结果自动保存为当前孩子的学习记录
- 错题手动录入（含日期、学科、预置分类/自定义分类、状态、标签）
- 错题详情面板（完整结构化字段查看）
- 错题编辑（在详情页直接修改错题内容）
- 状态快捷更新（在详情页直接改为未复习/已复习/已掌握/需再次复习）
- 错题多条件筛选（日期范围、学科、类别关键词、状态、标签）
- 重复错题检测与关联提示（保存前检测相似题，可关联历史或按新题保存）
- OCR 草稿位（粘贴识别文本 -> 自动生成学科/类别/来源草稿）
- 语音转写（开源 `faster-whisper`）
- 导出 TXT / Markdown / PDF（支持简洁版与详细版，支持按日/周/月/自定义）
- 导出策略（可排除“已掌握”；可优先“需再次复习”）
- 自动定期导出（按日/周/月，到点自动生成导出记录）
- 薄弱点归纳（高频错误、连续多周重复、模式关键词）
- 最简提醒（站内提醒 + 可选浏览器系统通知）
- 本地备份与恢复（导出 JSON / 导入并覆盖恢复）
- 敏感操作二次确认（删除/导入恢复）
- 操作审计日志（导出/备份/删除等关键行为记录）

## 1. 启动与测试

复制 `.env.example` 为 `.env.local`，在本机填写 DeepSeek API Key：

```bash
DEEPSEEK_API_KEY=
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

`.env.local`、教材原文件和解析结果均已被 Git 忽略。不要把真实密钥写入源码或提交到仓库。

```bash
npm start
```

默认地址：`http://localhost:5173`

```bash
npm test
```

## 2. 语音转写（开源）

转写引擎：`faster-whisper`

安装依赖（推荐 Python 3.11 虚拟环境；`faster-whisper` 目前不支持 Python 3.12+）：
```bash
uv venv .venv311 --python 3.11
uv pip install --python .venv311/bin/python -r scripts/requirements.txt
```

如遇音频解码问题，请安装 `ffmpeg`。

启动服务时可指定解释器（让后端 OCR/转写脚本使用该 Python）：
```bash
PYTHON_BIN=.venv311/bin/python npm start
```

转写接口：
- `POST /api/transcribe`
- 请求体：录音二进制（`audio/webm` 等）
- 返回：`{ ok, engine, language, text }`

## 3. 图片 OCR（开源）

OCR 引擎：`rapidocr_onnxruntime`

安装依赖同上（`scripts/requirements.txt` 已包含）。

OCR 接口：
- `POST /api/ocr`
- 请求体：图片二进制（`image/jpeg`、`image/png`、`image/webp` 等）
- 返回：`{ ok, engine, text, lines }`

## 4. 页面功能流程

### 4.1 登录
输入手机号（11 位大陆号）或邮箱即可登录，本地自动创建家长账号。登录标识用于匹配本机 SQLite 中的对应账户；同一标识再次登录时，会恢复该账户的孩子档案、错题、复习进度和费曼学习记录。

### 4.2 页面结构（新版）
- 左侧选择当前孩子和功能，右侧显示对应工作区
- 首次使用时右侧直接展示建档表单；建档后自动进入“讲给 AI”
- 主要功能：复习 / 录入 / 讲给 AI / 薄弱点 / 导出 / 设置

### 4.3 讲给 AI
- 后台先按孩子年级和学科自动检索公共教材，家长也可以上传补充教材
- 选择学科并填写本次讲解主题；一般无需手动选择教材
- 孩子可以直接输入，也可以录音转写后提交
- 命中教材时，服务端只把讲解、年级、学科、主题和相关教材片段发送给 DeepSeek，并要求逐项核对正确性
- 没有可靠命中时，系统明确降级为通用知识评估，不会伪装成教材核对结果
- AI 返回总分、准确性、完整性、清晰度、举例能力、不清楚点、不熟悉点、改进讲法和追问
- 评分结果自动保存到当前孩子的学习记录

公共教材的解析文本保存在本机 `data/textbooks/`，不会进入 Git。使用 AI 评分时，相关教材片段和孩子的讲解内容会发送到 DeepSeek API，孩子姓名不会发送。

批量导入公共教材：

```bash
npm run import:textbooks -- "数学=/教材/数学" "英语=/教材/英语" "语文=/教材/语文"
```

### 4.4 错题录入（极简）
- 默认核心字段：孩子、日期、学科、类别、错题内容
- 其余字段放在“更多选项（可选）”中，降低录入负担
- 或上传图片点“上传图片并识别”，OCR 结果会自动填入“OCR 原文”
- OCR 后会尝试从图片元数据推断日期，并弹确认是否填入记录日期
- 再点“按 OCR 生成草稿”，自动填学科/类别/来源/日期/原题
- 学科选择后会自动给出该学科预置分类，仍可切换到“自定义”
- 若已有语音转写结果，可点“把语音结果填入错题内容”
- 保存时若检测到相似历史错题，会提示可直接关联；也可选择按新题保存或取消

### 4.5 错题列表与详情
- 列表支持按日期范围、孩子（当前/全部/指定）、学科、类别关键词、状态、标签筛选
- 点击“查看详情”可查看完整结构化字段（ID、日期、学科、类别、原题、错答、正答、解析、建议、来源、状态、标签、关联历史错题）
- 详情页可“快捷更新状态”
- 详情页可进入“编辑错题”，保存后覆盖原记录并更新更新时间
- 详情页支持“删除该错题”，并触发统一二次确认

### 4.6 导出
在导出区选择：
- 导出周期（按日 / 按周 / 按月 / 自定义）
- 孩子
- 开始/结束日期
- 模板（简洁打印版 / 详细讲解版）
- 导出策略（是否排除“已掌握”、是否优先“需再次复习”）

可直接下载：
- TXT（`.txt`）
- Markdown（`.md`）
- PDF（`.pdf`）

导出历史会在页面内展示最近 10 次，并支持一键重新下载。

### 4.7 自动导出
- 支持设置按日/按周/按月、时间、目标孩子、导出模板、导出格式
- 支持自动导出同样的导出策略（排除“已掌握”/优先“需再次复习”）
- 到时间会自动生成导出记录（本地版不自动触发下载）
- 可在导出历史点击“下载”获取文件

### 4.8 薄弱点归纳
- 可选分析范围：当前孩子 / 全部孩子
- 可选时间窗口：近 30/90/180 天或全部历史
- 输出三类结果：高频错误、连续多周重复、模式关键词
- 若样本不足会明确提示“样本不足”

### 4.9 提醒
支持每周/每月提醒时间。当前是最简本地方案：
- 页面打开时检查是否到提醒点
- 弹站内提醒
- 若已授权系统通知，则同步弹系统通知

### 4.10 本地备份与恢复
- 支持“一键导出备份 JSON”
- 支持“选择 JSON 文件 -> 导入并恢复”
- 导入前有统一二次确认，恢复后会覆盖当前账户的本地数据并写入 SQLite

### 4.11 操作审计
- 敏感操作（导入恢复、删除错题）通过二次确认防误操作
- 提供最近 20 条操作审计日志（时间、操作、结果、详情）

## 5. 数据存储说明

主数据保存在本机 `data/review-notebook.sqlite`，目录和数据库文件均已被 Git 忽略。每个手机号或邮箱使用哈希账户键隔离，SQLite 不额外保存登录标识明文。数据库、WAL 和共享内存文件权限限制为仅当前系统用户可读写。

浏览器的 `mistake-book-state-v1` 继续作为当前页面缓存和故障降级副本。登录时从 SQLite 恢复账户数据；建档、错题、复习、费曼记录、提醒和导入等变更会自动写回 SQLite。

主要字段：
- `users`
- `children`
- `mistakes`
- `exports`
- `auditLogs`
- `reminder`
- `currentUserId`
- `currentChildId`
